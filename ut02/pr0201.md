# PR0201 - Administración remota en Windows

En esta práctica vamos a configurar un servidor Windows Server 2019 en su versión Core y lo prepararemos para poder administrarlo de forma remota utilizando diferentes métodos.

## 1. Configuración inicial de Server Core (Post-instalación)

Al instalar la versión Core, no disponemos de interfaz gráfica estándar. Lo primero es cambiar de la consola `cmd` al intérprete de PowerShell escribiendo `powershell`. 

### Cambio de nombre e IP
Para cambiar el nombre del equipo, utilizamos el siguiente cmdlet y reiniciamos:

```powershell
Rename-Computer -NewName Core2019 -Restart
